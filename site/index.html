Автономный маркетинг для турагентства —
с платформой управления

Агент генерирует контент-план и тексты постов, готовит промпты для Higgsfield, собирает брендированные обложки, публикует в Telegram и учится на аналитике. Вы модерируете и настраиваете всё визуально.

🚀 Развернуть свою копию (Render) Запустить локально Скриншоты
Это демо-витрина на GitHub Pages (только статика). Сама платформа — серверное приложение (Next.js + SQLite): разверните её на Render в пару кликов или запустите локально.

Возможности

⚡ Генерация плана на неделю

Черновики по рубрикам, ротации направлений и вашему расписанию. Тексты пишет Claude (или встроенные шаблоны без ключа).

📝 Модерация

Ничего не публикуется без одобрения: правьте тексты TG/IG, дату, обложку; одобряйте или отклоняйте.

🎨 Единый визуальный стиль

Обложки Reels 1080×1920, IG 1080×1350, TG 1280×720 из бренд-цветов + экспорт в PNG в полном разрешении.

🎥 Связка с Higgsfield

Агент готовит детальный промпт в стиле бренда; готовое видео загружается к посту и становится фоном обложки.

🚀 Публикация в Telegram

Bot API: текст и фото, ретраи, обработка лимитов, автопубликация по расписанию через cron.

📈 Аналитика и обучение

Рост подписчиков, ER, охват, лучшие посты и рубрики; ежедневный сбор подписчиков TG-канала в базу.

Конструктор обложек — попробуйте вживую

Тот же шаблон, что в платформе: меняйте переменные и бренд-цвета.

Платформа изнутри

Кликните по скриншоту, чтобы увеличить.

Как запустить платформу

Вариант 1 — облако: нажмите «Развернуть на Render», войдите через GitHub, заполните логин/пароль и токены Telegram — через ~5 минут получите свою ссылку вида markening-agent.onrender.com. Вариант 2 — локально (Node.js 20+, база наполнится демо-данными): 

git clone https://github.com/xondamirx9/MarkeningAgent.git
cd MarkeningAgent
npm install
cp .env.example .env   # токены Telegram / ключ Claude — по желанию
npm run dev            # → http://localhost:3000  (admin / admin123)
