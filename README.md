# Маркетинговый агент турагентства — веб-платформа

Платформа управления автономным маркетинговым агентом для туристического агентства:
генерация контент-плана, модерация постов, единые визуальные шаблоны, контент-календарь,
публикация в Telegram и аналитика — всё настраивается и просматривается визуально.

## Возможности

- **Обзор** — подписчики TG/IG со спарклайнами, ER, очередь модерации, ближайшие публикации, лучшие посты.
- **Модерация** — очередь черновиков: текст для Telegram и Instagram, промпт для Higgsfield,
  превью брендированной обложки; одобрить / отклонить / отредактировать / сменить дату / опубликовать сейчас.
- **Кнопка «Сгенерировать план на неделю»** — агент создаёт черновики по включённым рубрикам,
  ротации направлений и расписанию. С `ANTHROPIC_API_KEY` тексты пишет Claude, без ключа — встроенные шаблоны.
- **Календарь** — месячная сетка с постами по дням и статусами.
- **Шаблоны** — живой предпросмотр обложек трёх форматов (Reels 1080×1920, IG 1080×1350, TG 1280×720)
  с подстановкой переменных и бренд-цветов из настроек.
- **Аналитика** — рост подписчиков (90 дней), вовлечённость по неделям, дневной охват,
  лучшие посты, сравнение рубрик, сравнение каналов.
- **Конкуренты** — таблица из 12 игроков с ER/частотой/форматами + выводы «как отстроиться».
- **Настройки** — бизнес-профиль, бренд-цвета, частота и дни постинга, время публикаций по каналам,
  вкл/выкл рубрик и их вес, автопубликация, статус интеграций.
- **Публикация в Telegram** — через Bot API (текст/фото, ретраи, обработка rate limit).
- **Загрузка медиа** — видео/фото из Higgsfield прикрепляется к посту и становится фоном обложки.
- **Экспорт обложек в PNG** — кнопка «Скачать обложку PNG» на странице поста рендерит
  шаблон в полном разрешении (Playwright screenshot); нужен Chromium
  (`npx playwright-core install chromium` или `CHROMIUM_PATH` в `.env`).
- **Сбор метрик** — `/api/cron` ежедневно снимает подписчиков Telegram-канала в базу.
- **Документация** — `docs/`: маркетинговая стратегия, анализ конкурентов (+CSV),
  бренд-гайд, инструкции по настройке Telegram и Instagram Graph API.

## Стек

Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · SQLite (better-sqlite3) · Recharts ·
Anthropic SDK (опционально). База и загрузки лежат в `data/` (в git не попадают);
при первом запуске база наполняется демо-данными, чтобы всё можно было посмотреть сразу.

## Запуск локально

```bash
npm install
cp .env.example .env   # заполните при необходимости
npm run dev            # http://localhost:3000
```

Логин по умолчанию: **admin / admin123** (меняется в `.env`).

Продакшен:

```bash
npm run build
npm start
```

Деплой — любой VPS/сервис с Node 20+ и постоянным диском для `data/`
(Vercel не подойдёт из-за файловой SQLite — используйте Railway/Fly/VPS).

## Переменные окружения

| Переменная | Обязательна | Описание |
|---|---|---|
| `ADMIN_LOGIN` / `ADMIN_PASSWORD` | нет (admin/admin123) | Доступ в платформу |
| `AUTH_SECRET` | в проде — да | Подпись сессионных cookie |
| `TELEGRAM_BOT_TOKEN` | для публикации | Токен бота от @BotFather |
| `TELEGRAM_CHANNEL_ID` | для публикации | `@username` или ID канала (бот — админ канала) |
| `ANTHROPIC_API_KEY` | нет | Тексты постов пишет Claude; без ключа — шаблоны |
| `ANTHROPIC_MODEL` | нет | По умолчанию `claude-opus-4-8` |
| `CRON_SECRET` | нет | Защита `/api/cron` (`Authorization: Bearer <секрет>`) |

## Настройка Telegram

1. Создайте бота у [@BotFather](https://t.me/BotFather) → `TELEGRAM_BOT_TOKEN`.
2. Добавьте бота **администратором** вашего канала с правом публикации.
3. `TELEGRAM_CHANNEL_ID` = `@username` канала (или числовой ID для приватного).
4. Кнопка «Опубликовать сейчас» на посте отправит его в канал.

## Автопубликация по расписанию

Включите автопубликацию в «Настройках» и дёргайте `/api/cron` каждые 5 минут:

```cron
*/5 * * * * curl -s -H "Authorization: Bearer $CRON_SECRET" https://your-host/api/cron
```

Эндпоинт публикует одобренные/запланированные посты, чьё время наступило.

## Что автоматизировано, а что нет (честно)

- **Telegram** — публикация полностью автоматическая через Bot API.
- **Instagram** — Graph API требует Business/Creator-аккаунт, привязанный к Facebook Page,
  и ревью приложения Meta. Пока это не настроено, пост помечается опубликованным,
  а в Instagram выкладывается вручную (текст для IG уже готов в карточке поста).
- **Higgsfield** — публичного API нет: агент генерирует детальный промпт (кнопка «Скопировать»),
  вы генерируете видео вручную и загружаете файл к посту — платформа накладывает брендированную обложку.
- **Парсинг конкурентов** — Instagram запрещает автоматический парсинг; для Telegram можно
  использовать Telethon по публичным каналам. В платформе данные конкурентов хранятся в таблице
  `competitors` (SQLite) и редактируются вручную/скриптом.

## Структура

```
app/
  (dash)/            — защищённые страницы: обзор, queue, calendar, analytics, competitors, templates, settings, posts/[id]
  api/               — auth, posts (CRUD/действия/медиа), settings, generate, cron, media
  login/             — вход
components/          — Nav, Cover (шаблоны обложек), Charts (Recharts), PostEditor, SettingsForm…
lib/                 — db (SQLite + сид), agent (генерация плана), publish (Telegram), auth, format
data/                — app.db и загрузки (gitignored)
```
