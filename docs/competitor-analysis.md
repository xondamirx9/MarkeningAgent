# Анализ конкурентов

> Методика и выводы. Сырые данные — в `docs/competitors.csv` и в таблице «Конкуренты»
> платформы (SQLite `competitors`). Демо-данные при первом запуске — замените реальными.

## Методика сбора

- **Telegram (автоматизируемо):** публичные каналы читаются через Telethon (MTProto).
  Скриптом собираются: подписчики, частота постов, средние просмотры, реакции → ER.
  Это допустимо для публичных каналов; уважайте rate limits.
- **Instagram (только полуручной режим):** автоматический парсинг запрещён правилами Meta
  и технически блокируется. Данные (подписчики, лайки/комментарии на 10 последних постов,
  частота) вносятся вручную раз в 2–4 недели в таблицу платформы.

ER считаем как (реакции + комментарии + репосты) / просмотры (TG) или / подписчики (IG).

## Выводы по рынку (12 игроков, Ташкент + сильные игроки СНГ)

**Что делают хорошо:**
- Лидеры (Travel Hub Asia, GoTravel) постят 9–12 раз в неделю — частота решает охват.
- Reels с конкретными ценами дают лучший ER (3–4%+).
- Живые отзывы и UGC (Anor Travel) — самый дешёвый источник доверия.

**Типовые ошибки — наши возможности:**
1. Нет единого стиля обложек → лента выглядит как барахолка. **Мы:** бренд-шаблоны на каждый пост.
2. Никто не обещает срок сборки тура. **Мы:** «тур за 24 часа» в каждом CTA.
3. Только плюсы отелей → недоверие. **Мы:** честные обзоры с минусами.
4. Медленные ответы в комментариях. **Мы:** SLA 15 минут в рабочее время.
5. Telegram без кнопок брони. **Мы:** кнопка/CTA под каждым постом.
6. Instagram «по остаточному принципу» у TG-ориентированных игроков. **Мы:** отдельный текст под IG в каждом посте.
7. Спамный тон (TezTrip: высокая частота, ER 1.6%) — частота без пользы выжигает базу.
8. Нет закулисья → агентства безлики. **Мы:** рубрика «Закулисье» еженедельно.
9. Гайды без структуры «сохрани на потом». **Мы:** чек-листы и карусели.
10. Никто не переиспользует отзывы как рекламные креативы. **Мы:** отзыв → карточка → Reels.
