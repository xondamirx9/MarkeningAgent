# Бренд-гайд визуального контента

Единый стиль для всех обложек видео и постов. Реализован в двух местах, которые всегда
должны совпадать: `components/Cover.tsx` (превью в интерфейсе) и `lib/cover-render.ts`
(рендер в PNG через Playwright). Цвета и название бренда подставляются из «Настроек».

## Палитра

| Роль | По умолчанию | Где меняется |
|---|---|---|
| Основной (плашка бренда) | `#2a78d6` | Настройки → Бренд-стиль |
| Акцент (бейдж «Горящий тур» / «Акция») | `#eda100` | Настройки → Бренд-стиль |
| Текст на тёмном | `#ffffff` | фиксирован |
| Затемняющий градиент | rgba(0,0,0,.35→0→.55) сверху вниз | фиксирован |

Фон — видео/фото из Higgsfield; до загрузки медиа используется детерминированный
градиент по названию направления (одно направление — всегда один и тот же оттенок).

## Типографика

Системный sans (system-ui / Segoe UI): без лицензионных рисков, одинаково рендерится
в превью и в PNG. Иерархия: направление 40px/600 → заголовок 76px/800 (64px для TG
1280×720) → цена 52px/800 на белой плашке.

## Композиция (все форматы)

- Верхняя полоса: слева плашка бренда «✈️ {название}», справа — бейдж (если задан).
- Нижняя треть: направление → заголовок-хук → цена на белой плашке.
- Нижняя треть всегда свободна в исходном видео — промпты Higgsfield это требуют
  («negative space in the bottom third», генерируется автоматически).

## Форматы

| Формат | Размер | Использование |
|---|---|---|
| `reels` | 1080×1920 | Обложка Reels / вертикального видео, сторис |
| `ig_post` | 1080×1350 | Лента Instagram, карусели (первый слайд) |
| `tg_post` | 1280×720 | Картинка к посту Telegram |

Готовый PNG: кнопка «Скачать обложку PNG» на странице поста
(`GET /api/posts/{id}/cover`). Карусель собирается из нескольких `ig_post`-обложек
с разными заголовками (слайд 1 — хук, далее — пункты гайда).

## Правило единства с Higgsfield

Каждый промпт Higgsfield, который генерирует агент, включает: golden-hour свет,
teal-and-amber грейдинг, чистую композицию и пустую нижнюю треть. Так любое видео
после наложения обложки выглядит частью одной ленты.
