# Настройка Telegram-публикации

Нужны два значения в `.env`: `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHANNEL_ID`.

## Шаг 1. Создайте бота

1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Задайте имя (например, «Oscar Publisher») и username (например, `oscar_publisher_bot`).
3. BotFather вернёт токен вида `1234567890:AAE…` → это `TELEGRAM_BOT_TOKEN`.

## Шаг 2. Дайте боту права в канале

1. Откройте свой канал → «Управление каналом» → «Администраторы» → «Добавить администратора».
2. Найдите бота по username и добавьте с правом **«Публикация сообщений»**
   (остальные права можно выключить).

## Шаг 3. Укажите канал

- Публичный канал: `TELEGRAM_CHANNEL_ID=@username_канала`.
- Приватный канал: перешлите любой пост канала боту [@userinfobot](https://t.me/userinfobot)
  или временно добавьте [@getidsbot](https://t.me/getidsbot) — нужен числовой ID вида
  `-100xxxxxxxxxx`.

## Шаг 4. Проверка

Перезапустите платформу, откройте «Настройки» — пункт «Telegram Bot API» должен стать
зелёным. Возьмите любой запланированный пост → «🚀 Опубликовать сейчас».

## Как публикует платформа

- Загружено фото (jpg/png) → `sendPhoto`; видео (mp4/mov) → `sendVideo`; webm → `sendDocument`.
- Медиа не загружено → платформа рендерит брендированную обложку в PNG и шлёт её
  (нативный рендер, браузер не нужен).
- Текст длиннее лимита подписи (1024 символа) → медиа уходит с заголовком,
  полный текст — отдельным сообщением следом.
- Rate limit 429 обрабатывается автоматически (пауза `retry_after` + до 3 попыток).
- Ежедневно `/api/cron` дополнительно снимает число подписчиков канала
  (`getChatMemberCount`) в метрики. Просмотры/реакции Bot API не отдаёт — для них
  нужен MTProto (Telethon) или ручной ввод.
